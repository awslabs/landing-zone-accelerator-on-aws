    ReadonlysendToS3

    sendToS3: boolean

    Send to S3 (Required)

    Determines whether sending SessionManager logs to S3 is enabled. When enabled, the accelerator sends the session manager logs directly to the central log bucket in the LogArchive account, which resides in the centralized logging Region (logging.centralizedLoggingRegion, the home Region by default).

    Because that bucket is single-Region, instances in any other enabled Region write to it cross-Region. A Region-scoped Amazon S3 gateway VPC endpoint cannot reach a bucket in another Region, so in a fully private Region (VPC endpoints only, no internet egress) that is not the centralized logging Region, Session Manager connections that require this log destination fail to establish and open a blank screen. For those Regions, enable sendToCloudWatchLogs instead (it writes to a Region-local log group that the accelerator forwards to the central bucket) or exclude the Region with excludeRegions.

    Optional ReadonlyidleSessionTimeout

    idleSessionTimeout?: number

    Idle Session Timeout (Optional)

    The number of minutes of inactivity to allow before a session ends.

    Valid values range from 1 to 60 minutes. When undefined the input is left out of the session document and sessions run at the Session Manager default of 20 minutes.

    This is not a hard cap on session length. The idle timer is reset by client side activity, which includes terminal and browser window resize events as well as session reconnects, so a session held open by a client that keeps emitting such events never goes idle. Use maxSessionDuration when an absolute session limit is required.

    See

    Specify an idle session timeout value for more information

    Optional ReadonlymaxSessionDuration

    maxSessionDuration?: number

    Maximum Session Duration (Optional)

    The maximum number of minutes a session is allowed to run before it ends, regardless of activity.

    Valid values range from 1 to 1440 minutes. When undefined the input is left out of the session document and no maximum duration is enforced.

    See

    Specify a maximum session duration for more information

    Optional ReadonlycloudWatchStreamingEnabled

    cloudWatchStreamingEnabled?: boolean

    CloudWatch Streaming Enabled (Optional)

    Determines whether session data is streamed continuously to CloudWatch Logs.

    Requires sendToCloudWatchLogs to be enabled. When true, session data is streamed to the log group as the session runs. When false, session logs are delivered to the log group once at the end of the session. When undefined the input is left out of the session document and the Session Manager default applies.

    Continuous streaming sends more data to CloudWatch Logs than end of session delivery, which carries the corresponding ingestion cost and retention consequences.

    Optional ReadonlyshellProfile

    shellProfile?: ISessionManagerShellProfileConfig

    Shell Profile (Optional)

    Per operating system session preferences, including commands run when a session starts.

    The commands in a shell profile run on every in-scope managed node when a session starts, so this property puts executable content into the global configuration file. Review values with the same care as any other deployed code.

    The accelerator is the only source of this value. A shell profile set outside the accelerator is removed the next time the session document is written, so an injected profile does not survive.
